১. Deen Connect কী এবং কেন ব্যবহার করবেন?

Deen Connect হলো একটি সহজ, দ্রুত এবং নির্ভরযোগ্য লাইভ ভিডিও মিটিং সিস্টেম। এটি Google Sheets-এর উপর ভিত্তি করে তৈরি। এর মাধ্যমে আপনি অনলাইন ক্লাস, বৈঠক, আলোচনা বা যেকোনো ধরনের লাইভ মিটিং করতে পারবেন।

এই সিস্টেমের সুবিধা:

  • কোনো অতিরিক্ত সফটওয়্যার ইনস্টল করতে হয় না
  • শুধু ব্রাউজার থাকলেই চলে
  • মোবাইল ও কম্পিউটার দুটোতেই ভালো কাজ করে
  • মিটিং তৈরি ও জয়েন করা খুবই সহজ
  • Owner চাইলে সম্পূর্ণ নিয়ন্ত্রণ করতে পারেন

২. প্রথমবার সাইট খুললে কী দেখবেন?

  • প্রথমে ১২ সেকেন্ডের একটি সুন্দর Splash Screen আসবে।
  • Splash-এ Deen Connect-এর নাম, ডেভেলপারের নাম এবং ভার্সন দেখা যাবে।
  • Splash শেষ হলে মূল পেজ চলে আসবে।
  • উপরে Navigation মেনু থাকবে (Join, Create, Owner, About)।
  • বাম পাশে Sidebar থাকবে (☰ বাটনে চাপলে খুলবে)।

৩. Join Meeting করার সম্পূর্ণ নিয়ম

মিটিংয়ে যোগ দিতে চাইলে এই ধাপগুলো অনুসরণ করুন:

  • ধাপ ১: “Join Meeting” অংশে যান।
  • ধাপ ২: Room Name লিখুন (যে নামে Host মিটিং তৈরি করেছে)।
  • ধাপ ৩: যদি Room-এ পাসওয়ার্ড থাকে তাহলে পাসওয়ার্ড দিন। না থাকলে খালি রাখুন।
  • ধাপ ৪: আপনার Display Name লিখুন (মিটিংয়ে যে নামে আপনাকে দেখাবে)।
  • ধাপ ৫: “Join Meeting” বাটনে চাপুন।
যদি Host এখনো মিটিংয়ে না এসে থাকে, তাহলে একটি অপেক্ষা স্ক্রিন আসবে। Host জয়েন করলে আপনি স্বয়ংক্রিয়ভাবে মিটিংয়ে প্রবেশ করবেন।

৪. Create Meeting করার সম্পূর্ণ নিয়ম (Host-দের জন্য)

নতুন মিটিং তৈরি করতে চাইলে:

  • ধাপ ১: “Create Meeting” অংশে যান।
  • ধাপ ২: Host Username লিখুন।
  • ধাপ ৩: Host Password লিখুন।
  • ধাপ ৪: নতুন Room Name দিন (যেকোনো নাম হতে পারে)।
  • ধাপ ৫: প্রয়োজন হলে Room Password সেট করুন।
  • ধাপ ৬: আপনার Display Name লিখুন।
  • ধাপ ৭: দুটি অপশন পাবেন:
    • Create & Start → মিটিং সাথে সাথে শুরু হবে এবং আপনি জয়েন করবেন।
    • Create & Wait → মিটিং তৈরি হবে কিন্তু আপনি পরে জয়েন করবেন। অন্যরা অপেক্ষা করতে পারবে।

৫. উপরের হলুদ ব্যানার (Meeting চলছে) কীভাবে ব্যবহার করবেন

যখন কোনো মিটিং Active বা Waiting অবস্থায় থাকে, তখন পেজের উপরে একটি হলুদ ব্যানার দেখা যায়।

  • Join as Host বাটনে চাপলে Host Verification চাইবে। সঠিক Host Username ও Password দিলে আপনি Host হিসেবে জয়েন করতে পারবেন।
  • Join as User বাটনে চাপলে একটি বক্স খুলবে। সেখানে পাসওয়ার্ড (যদি থাকে) এবং আপনার নাম দিয়ে সরাসরি জয়েন করা যায়।

৬. Owner Dashboard কীভাবে ব্যবহার করবেন

Owner Dashboard হলো সিস্টেমের সবচেয়ে শক্তিশালী অংশ। এখানে গিয়ে আপনি পারবেন:

  • চলমান মিটিংয়ের সম্পূর্ণ তথ্য দেখতে
  • নতুন Host যোগ করতে
  • পুরনো Host ডিলিট করতে
  • মিটিং জোর করে বন্ধ (Force Close) করতে
  • Owner-এর নিজের Username ও Password পরিবর্তন করতে

Owner Dashboard খোলার নিয়ম:

  • “Owner Login” অংশে যান।
  • Owner Username এবং Password দিন।
  • “Open Owner Dashboard” বাটনে চাপুন।

৭. মিটিং শেষ করার সঠিক নিয়ম

মিটিং শেষ হলে Element/Jitsi-এর ভিতরের Leave বাটনে না চেপে সরাসরি সেই ট্যাবটি বন্ধ (Close) করে দিন।

ট্যাব বন্ধ করলে আপনি আবার Deen Connect পেজে ফিরে আসবেন।

৮. Sidebar ও Navigation কীভাবে ব্যবহার করবেন

  • উপরের বাম দিকের ☰ বাটনে চাপলে Sidebar খুলবে।
  • Sidebar থেকে Join, Create, Owner, Manual এবং About-এ যেতে পারবেন।
  • উপরের Navigation বাটনগুলো দিয়েও একই কাজ করা যায়।
